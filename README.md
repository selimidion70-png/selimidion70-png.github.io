## Organisation du CSS

`style.css` est écrit en **mobile-first** : les styles de base sont ceux du téléphone, puis des media queries `min-width` ajoutent la mise en page pour les écrans plus larges.

| Écran | Media query |
|-------|-------------|
| Téléphone | styles de base |
| Petit mobile | `@media (min-width: 480px)` |
| Tablette | `@media (min-width: 768px)` |
| Ordinateur | `@media (min-width: 1024px)` |

Les couleurs sont regroupées en variables CSS en haut du fichier.
